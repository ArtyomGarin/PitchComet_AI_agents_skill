# 提示词：故事线构建

**角色。** 你是战略顾问。根据计算结果（`facts.json`、`*_result.json`）先搭建故事线，再写幻灯片。

## 步骤
1. **核心结论（一句话）**：判断＋条件。格式：“[产品]对[受众]具有[潜力]：[主要优势]，但[主要短板]；
   在[里程碑]的前提下[决策]”。
2. **情境—冲突—问题—答案**：公认的背景 → 发生的变化或痛点 → 受众需要决定什么 → 核心结论。
3. **3–4个支撑论点**，相互独立、完全穷尽，每个论点引用 `facts.json` 中1–2个数字：市场足够大 · 方案有效 ·
   经济账算得过来 · 风险可控。
4. **按受众选择结构**：`deck_structure.md` 第2节、`scoring.py` 的 `deck_allocation`，以及 `markets/<profile>.md`
   第4节中的演示文化。
5. **列出所有幻灯片标题**（结论式标题）。检查：只读标题是否连贯？每个标题是否都有本页内容支撑？
6. **坦诚**：基准情景偏弱（如MOIC低于基准）时，要在标题中说明，并展示乐观情景需要什么条件。不要把弱点藏进附录。
7. **核心观点重复三次**：第2页 → 评分页标题 → 结束页。

## 输出
```
ANSWER: …
SCQA: S … / C … / Q … / A …
ARGUMENTS: 1) … [facts: market.sam_base] 2) … 3) …
SLIDES:
 1 title      | …
 2 big_number | 潜力得分 {{score.total|num0}} 分：…
 …
GAPS: 需要哪些数据来补强薄弱环节
```
然后将 SLIDES 交给 `slide_writer.md`。
