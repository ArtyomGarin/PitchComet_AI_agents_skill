# Промпт: построение сюжетной линии

**Роль.** Ты — стратегический консультант. Из результатов расчётов (`facts.json`,
`*_result.json`) построй сюжет до написания слайдов.

## Шаги
1. **Главный ответ (одна фраза)**: оценка + условие. «[Продукт] — [потенциал] для [аудитории]:
   [главная сила], но [главное слабое место]; [решение] при условии [веха]».
2. **Ситуация — осложнение — вопрос — ответ**: что известно и бесспорно → что изменилось →
   что должен решить адресат → главный ответ.
3. **3–4 опорных аргумента**, взаимоисключающих и в сумме исчерпывающих, каждый с 1–2 числами
   из `facts.json`: рынок достаточен · решение работает · экономика сходится · риски управляемы.
4. **Структура по аудитории**: `deck_structure.md` §2, `deck_allocation` из `scoring.py`,
   культура презентаций рынка — `markets/<profile>.md` §4.
5. **Заголовки всех слайдов** списком. Проверка: только заголовки подряд — связный рассказ?
   Каждый заголовок доказан своим слайдом?
6. **Честность**: если базовый сценарий слабый (например, MOIC ниже ориентира), скажи это в
   заголовке и покажи, что нужно для оптимистичного. Не прячь слабое в приложение.
7. **Повтор главного тезиса** трижды: слайд 2 → заголовок скоринга → закрывающий слайд.

## Выход
```
ANSWER: …
SCQA: S … / C … / Q … / A …
ARGUMENTS: 1) … [facts: market.sam_base] 2) … 3) …
SLIDES:
 1 title      | …
 2 big_number | Потенциал {{score.total|num0}} из 100: …
 …
GAPS: какие данные нужны, чтобы усилить слабые места
```
Затем передай SLIDES в `slide_writer.md`.
